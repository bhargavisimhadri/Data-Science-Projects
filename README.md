# 🌟 **End-to-End Data Science Project**

## 📌 **Overview**

This repository contains a complete **data science project pipeline**, demonstrating everything from raw data exploration to building and evaluating machine learning models.

The project uses popular Python libraries:

* **NumPy**
* **Pandas**
* **Matplotlib**
* **Seaborn**
* **Scikit-learn**
